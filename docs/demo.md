# Try Shards Code on the Pocket Pet example

The Pocket Pet is a small local browser project with a synthetic focus-timer feature. It is an example workspace, not a Shards Code installation or a claim about any model provider. The project source and its own run instructions are in [`examples/pocket-pet`](../examples/pocket-pet).

Build Shards Code by following the [source installation guide](installation.md#build-from-source). From the repository root, start the built CLI in the example directory:

```bash
cd examples/pocket-pet
node ../../dist/cli.js "Read the project instructions and tests. Explain a small improvement before editing, then make it and run the documented checks."
```

Use an appropriate permission mode and inspect proposed edits and commands before allowing them. The example's documented test and browser checks must be run separately; a successful agent session alone does not establish browser behavior.

All example data is synthetic. Do not use the repository demo as evidence of live MiniMax service availability, quality or performance. MiniMax remains one optional provider; the independent Shards project has no MiniMax affiliation or support channel.
