# Community channels

This source snapshot does not announce official Shards Code chat groups, Discord or Feishu channels, invite-only test programs, or recurring community events. Do not reuse MiniMax-owned community links, private group policies or internal test-build material for this fork.

For project questions and non-sensitive bug reports, use the [Shards Code issue tracker](https://github.com/Shards-foundation/shards-code/issues) after the repository is available. Avoid posting credentials, account identifiers, session data, private project content or vulnerability details. The current support limitations are described in [Community support status](oncall.md), and sensitive-report guidance is in [Security](../../SECURITY.md).

If Shards Foundation later creates community channels, publish their purpose, moderation rules, privacy expectations and responsible contacts only after those channels and owners are confirmed.
