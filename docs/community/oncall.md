# Community support status

This independent Shards Code source snapshot does not announce a community on-call rota, support chat, private security inbox, or response-time SLA. Do not treat upstream MiniMax support arrangements as support for this fork.

For non-sensitive questions and bugs, use the [Shards Code issue tracker](https://github.com/Shards-foundation/shards-code/issues) after the repository is available. Do not include API keys, account or session data, real project content, or exploit details in public issues. Follow [Security](../../SECURITY.md) for sensitive reports; if no private reporting channel is enabled, ask the repository owner for a private route before sharing details.

Opening an issue does not promise triage by a particular date, implementation, or release. Repository owners should publish support commitments only after assigning responsible maintainers and verifying that the corresponding channels are active.
